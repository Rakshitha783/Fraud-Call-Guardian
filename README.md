# Fraud Call Guardian

AI-powered real-time fraud call detection and prevention platform.

## Project Structure

- `frontend/` — React frontend
- `backend/` — FastAPI backend and AI services
- `docs/` — Project documentation

## Core Pipeline

Call / Audio
↓
Speech-to-Text
↓
Language Detection
↓
NLP Analysis
↓
Scam Detection
↓
Risk Scoring
↓
Explainable Warning
↓
Evidence / Report
